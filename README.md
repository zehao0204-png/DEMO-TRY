# 周末有解 · 上海城市玩法盲盒

一款原生微信小程序 MVP：用户选择想要的体验，抽取一个具体的上海城市挑战；完成并评价后，推荐会逐渐贴近用户偏好，同时保留盲盒的意外感。

## 已实现

- 上海限定玩法盲盒，体验标签可选
- 一次只揭晓一个具体任务，减少选择困难
- 收下、替换、完成或放回挑战
- 完成后的快速评价、标签反馈和一句话记录
- 本地探索档案、区域统计、成就印章和城市人格
- 基于真实反馈的轻量个性化推荐（70%偏好、20%邻近探索、10%随机惊喜的产品原则）
- 微信本地存储，无需服务器即可体验完整闭环

## 在微信开发者工具中运行

1. 安装并打开微信开发者工具。
2. 选择「导入项目」。
3. 选择本仓库所在文件夹。
4. AppID 可使用测试号；仓库中的 `touristappid` 仅用于本地预览。
5. 点击「编译」。

## 本地校验

推荐逻辑没有第三方依赖，可直接运行：

```bash
node tests/recommend.test.js
```

## 项目结构

```text
pages/index       玩法盲盒
pages/challenge   本周挑战与完成反馈
pages/explore     探索档案与城市人格
data/plays.js     上海玩法样本库
utils/recommend   推荐与画像逻辑
```

## MVP边界

当前版本使用经过整理的本地玩法样本和本地存储，暂未接入登录、内容后台、地图数据接口和云端同步。验证用户是否愿意持续完成城市挑战后，再投入这些基础设施。
